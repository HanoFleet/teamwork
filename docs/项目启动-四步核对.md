# 项目启动四步核对

本文件按第 7 课“项目启动：四步”的完成现象核对仓库现状。结论：**四步的工程产物都已具备；第 1、2、3、4 步的文件和可运行骨架已完成，剩余是远端 CI、主干保护和组员独立启动。**

## 现在能否提交

**文件层面可以提交。** README、`.gitignore`、LICENSE、`.env.example`、协作约定、日期命名的 change、可运行 Compose、`/live`/`/health`、日志、停机、门禁和报告都已具备。交之前建议完成：

1. 推送 `change/platform-foundation` 并合并到 `main`（或先推分支让主人评审）。
2. 在 GitHub 设置 `main` 保护规则，禁止直接推送。
3. 每位组员按 README 独立克隆、填 `.env`、跑 `docker compose up -d --wait`，确认 `/live` 和 `/health`。
4. 推送后确认 GitHub Actions 的 `check` 和 `grade` 首次运行成功。
