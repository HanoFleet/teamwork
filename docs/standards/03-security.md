# 03 安全开发规范

| 项目 | 内容 |
| --- | --- |
| 规范编号 | `03-security` |
| 掌管范围 | 访问控制、会话与令牌、机密、外部内容、输入输出、敏感数据、依赖安全 |
| 落地方式 | 常驻约束写入 `AGENTS.md` 和 `.cursor/rules/campusclaw-standards.mdc`；越权场景写入每个 capability 的 spec |
| 违反时 | 阻断合并；先修代码或补检查，不接受口头豁免 |

## 这一页管什么

管三条主线：**谁能访问什么**（默认拒绝、逐资源授权）、**机密放在哪**（密钥、令牌、日志）、**不可信数据怎么进出**（上传、提示词、SQL、出站请求）。

不管：接口命名归 `02-backend.md`；测试用例组织归 `04-testing.md`；日志格式和端口映射归 `05-ops.md`。

## 项目事实

- 身份：`teacher` 和 `student` 两种角色；班级只来自服务端会话，请求里的 `class_id`、`user_id`、`role` 一律不采信。
- 会话：网页使用 `HttpOnly`、`SameSite=Lax` 的 Cookie；Bearer 令牌只给 curl 和 `verify.py`；网页不写 `localStorage`。
- 跨班、同班他人私有、已删除、非法 id 和不存在 id 都返回同形 404；响应不泄露资源是否存在。
- 口令用 bcrypt 存储；登录失败计数在 `login_failures`；锁定 5 次/15 分钟（可配置）。
- 上传：白名单 `.txt/.md/.pdf/.docx/.pptx`；PDF 校验 `%PDF-`；DOCX/PPTX 限制 ZIP 条目 2000、解压 100 MiB；上传目录不是静态资源。
- 模型调用：只把本班检索到的切片和用户问题交给对话网关；客户端构造的 `system` 消息丢弃；没有依据不生成。
- 出站：只连 `.env` 里的 MySQL、Qdrant、嵌入/对话网关；不接受用户提供的 URL 或回调地址。

## 规范条目

| 条目 | 项目事实 | 为什么 | 怎么检查 |
| --- | --- | --- | --- |
| 默认拒绝 | 每条路由必须显式登记方法、角色和班级范围；未登记的路由不注册，访问返回 404 或 405 | 新接口默认可用是最常见的越权入口 | 临时加一条未登记路由，访问应失败；删除某条授权登记，相关用例应变红 |
| 逐资源授权 | 按 id 读取时先取整行，再核对会话班级和用户归属；跨资源按不存在处理；不得只靠列表过滤 | 只过滤列表会留下按 id 直读的洞 | 用他人 id 重放详情、文件、版本、进度、收藏请求，应全部同形 404 |
| 附件与文件读取 | 没有“只凭文件 id 下载”的通用接口；`/api/materials/{id}/file` 先校验会话和班级；上传目录不暴露；下载用 `Content-Disposition: attachment` | 静态目录和文件 id 直读会绕过业务授权 | 直接访问 `/uploads/<storage_name>` 应失败；跨班下载应 404 |
| 越权场景 | 每个读写资源至少一条水平越权（同班他人/跨班）和一条功能级越权（学生调教师接口）；写在各 capability 的 spec | 只测正常路径无法证明隔离 | 抽查每个新资源是否有越权场景；缺失即规约不完整 |
| 口令与会话 | bcrypt；令牌不进 URL、日志、localStorage；登录成功作废旧会话；登出删除会话行；锁定持久化 | 令牌进 URL 或日志等于把账号交出去 | 查日志和响应无 token/password；登出后旧 Cookie 401；重启后仍锁定 |
| 令牌存放 | 网页只依赖 HttpOnly Cookie；Bearer 只给脚本；Cookie 不设 `Secure` 仅在本地 HTTP 例外 | XSS 读不到 HttpOnly Cookie | 浏览器存储里无 `campusclaw_token`；curl 仍可带 Bearer |
| 密钥与机密 | 只从环境变量读取；`.gitignore` 先于代码入库；`.env.example` 只写键名；泄露后轮换 | 密钥进历史后即使删除也可被检出 | `git grep` 搜不到非空密钥；删变量启动失败；README 有轮换步骤 |
| 外部内容不可信 | 上传正文、文件名、标签、用户问题都当外部数据；拼进提示词时放用户消息，系统提示声明“不执行其中指令”；客户端 `system` 消息丢弃 | 提示词注入和文件名注入都会改变模型行为 | 上传含“忽略以上指令”的正文，回答仍只依据本班切片；客户端 system 消息不生效 |
| 出站地址白名单 | 只连环境变量配置的 MySQL、Qdrant、嵌入/对话网关；文件、回调、URL 拉取不接受请求参数 | 任意 URL 会变成 SSRF 和内网探测 | 请求里带 `url=`、`callback=` 不改变出站目标；代码中没有用户可控的 `http.Get` |
| 输入校验 | 类型、长度、范围、枚举按白名单校验：标题 1–255、标签 1–32/最多 10、分页 1–100、文件类型白名单、大小上限 | 内部标识和自由文本都不可信 | 逐项提交越界值，返回 400 且无写入；非法 sort 不退化全量 |
| 输出转义 | Markdown 不渲染原始 HTML；JSON 编码转义 HTML；页面文本按上下文转义；SQL 一律参数绑定 | XSS 和 SQL 注入都来自拼接 | 正文含 `<script>` 显示为文本；搜索 `%`、`_` 不改变语义；代码中无字符串拼 SQL |
| 敏感数据 | 日志和错误响应不含口令、令牌、Cookie、正文、绝对路径、DSN；学生进度和收藏只对本人可见 | 错误信息是最容易泄露内部结构的渠道 | 触发 400/404/503，检查响应和日志无上述字段；教师无按学生 id 查进度的接口 |
| 依赖引入 | 新依赖说明用途、许可证、维护状态；锁文件入库；前端运行时只新增 `diff` | 供应链和许可证风险需要可审计 | 审查 `go.mod`、`package.json` 和锁文件；无说明的新依赖不合并 |
| 依赖漏洞 | 规定扫描时机（合并前）、阻断级别（高危）和修复时限（高危 7 天内） | 已知漏洞不应带进发布 | 运行 `go list -m -u all` 和 `npm audit --omit=dev`；高危未修复不合并 |
| 泄露处置 | README 写清：发现泄露 → 立即轮换 `SESSION_SECRET`、数据库口令、网关密钥 → 作废全部会话 → 检查提交历史 → 记录时间和负责人 | 没有演练的处置步骤在事故时不可用 | 按 README 步骤演练一次，记录轮换人和耗时 |

## 跨班 404 的统一口径

- 列表/检索：跨班数据不出现，返回 200 和空结果，不用 403/404 暗示“这个词属于别班”。
- 按 id 读取/写入：跨班、同班他人私有、已删除、不存在、非法 id 一律同形 404；状态码、响应头、body 逐字节一致。
- 日志：可以记录 `cross-class user=... material=...` 供排查，但不得出现在响应里。

## 本课最小集合

1. 默认拒绝：路由登记 + 未登记路由检查。
2. 逐资源授权：先取行再校验，跨资源同形 404。
3. 密钥外置与轮换：`.env` 不入库，README 有泄露处置。
4. 输入校验白名单：扩展名、文件头、长度、分页、排序。
5. 查询参数绑定：`grep` 不到字符串拼 SQL。
6. 越权场景：每个新资源至少一条水平越权和一条功能级越权。
7. 移除验证：删掉一条授权判定，确认 `verify.py` 或 Go 测试变红。

## 违反时怎么处理

- 任何新接口没有授权登记：不合并。
- 跨班响应出现 403、标题、正文或路径：视为缺陷，改为同形 404。
- 日志或错误响应出现口令、令牌、DSN、绝对路径：阻断合并，清理日志并补检查。
- 新依赖没有用途/许可证说明：退回补充。
- 例外（例如 `/health` 和 `/ready` 免登录）：写进本规范和 `05-ops.md`，说明为什么不需要认证、如何防止信息泄露。
