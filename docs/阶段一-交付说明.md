## 3. 本版相对上一版的改动

1. **恢复可运行骨架**：从 `v2.0.0-baseline` 恢复 `backend/`、`frontend/`、Compose 和 `verify.py`，不再只交规约和归档包。
2. **健康语义**：新增 `/live` 存活、`/health` 就绪、`/ready` 别名；停 MySQL/Qdrant 时 `/health` 503，`/live` 仍 200。
3. **日志与停机**：`internal/logging` 单行 JSON + request ID；`internal/lifecycle` 在 SIGTERM 后排空，最多等 `SHUTDOWN_TIMEOUT_SECONDS`。
4. **配置外置**：`APP_VERSION`、`SHUTDOWN_TIMEOUT_SECONDS` 必填；缺失/越界启动失败。
5. **门禁与证据**：`make check` 串起规约/规范/strict/分层/密钥/变异/Go/前端；`make grade` 独立 Compose 14 项，生成 HTML/JSON 报告。
6. **前端依赖**：Vite 8.3.5、react-router-dom 7.18.5；`npm audit` 0 漏洞，构建通过。
7. **规约重排**：foundation 单独成 change 并归档；material-library 去掉重复的日志/就绪条款，保留迁移、页面壳层、全局搜索、嵌入配置和材料库业务。
8. **文档同步**：README、SPEC、AGENTS、四步核对、八类规范、数据字典和贡献记录都按“骨架已实现、材料库未实现”更新。

## 5. 评审方式

1. **启动**：按 README 填 `.env`，`docker compose up --build -d --wait`，看 `/live`、`/health`、`/ready`。
2. **门禁**：`make check` 和 `make grade`，看退出码和报告。
3. **规约**：读 foundation 的四份文件，再读 material-library 的 proposal/design，确认后者依赖已归档骨架。
4. **另起会话**：只给仓库路径和 change 名，要求按 `tasks.md` 实现，列出含糊点。
5. **规范常驻**：新开会话按 `docs/standards/02-backend.md` 加一个材料标签接口，核对分层、命名、错误码和幂等。
